# Trademark and naming policy

The code in this repository is licensed as [LICENSING.md](LICENSING.md)
describes: the server under AGPL-3.0, the app under PolyForm Strict. Those
licences cover **code**. Neither grants any right to the project's name, icon
or domain, and this file says so explicitly rather than leaving it to be
inferred.

## The marks

- the name **hqChat** / **hqchat**, in any capitalisation
- the hqChat app icon and any derivative of it
- the domain **hqchat.app** and the App Store listing name

## What you may do without asking

- **Refer to the project.** "a fork of hqChat", "compatible with the hqChat
  protocol", "based on hqChat", "originally by the hqChat project" — nominative
  use that describes a factual relationship is fine and always will be.
- **Write about it.** Research papers, reviews, security analyses, talks,
  teaching material. Name it freely; quote it; criticise it.
- **Run your own server.** Deploying the AGPL server, modified or not, is what
  its licence is for. Call it what it is ("a server running hqChat
  software"), not "hqChat".
- **Build the app yourself, for yourself.** The app's licence allows building
  and running it for noncommercial use; it does not allow changing or
  distributing it, whatever it is called.

## What you may not do without written permission

- **Ship a modified build under the name hqChat**, or under a name close
  enough to be confused with it, in any app store or distribution channel.
- **Use the app icon**, or a recognisable derivative, on any build that is not
  an official release.
- **Imply endorsement**, affiliation, review or approval by this project — for
  a fork, a service, a product, or a security claim.
- **Register** the name, a translation or transliteration of it, or a
  confusingly similar mark, as a trademark or as a domain intended to be taken
  for this one.

## Why this exists, in one paragraph

This is an end-to-end encrypted messenger. Its entire trust argument is that
you can read the code that makes the claim. Anyone may take the server code,
change it and run the result; that is deliberate. What it must not become is a
service or a build that does something different while wearing this name,
because a user choosing it cannot tell the two apart. Server forks are welcome.
Forks under this name are not, and the app is not licensed for forks at all.

## Builds of the app

The app's licence does not allow distributing it, modified or not. Only
official releases are distributed, under the name hqChat and with its icon.
